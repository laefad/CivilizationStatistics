# О проекте

Сайт для отслеживания рейтинга в клубе Civ VI и статуса сервера Minecraft.

# Для разработчиков

## Найстройка VS Code
1. Установить расширениe для vue - [Vue Language Features (Volar)](https://marketplace.visualstudio.com/items?itemName=Vue.volar)
2. Установить расширение для sass - [Sass (.sass only)](https://marketplace.visualstudio.com/items?itemName=Syler.sass-indented)

## Запуск

Введите команду

```
npm run dev
```
